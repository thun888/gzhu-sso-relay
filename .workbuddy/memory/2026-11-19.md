# 2026-11-19

## 登录授权记录

- 新增 `auth_events` 表与 `internal/audit` 记录器，登录成功/失败、登出、设备下线、授权确认/拒绝/撤销、应用登录均写入事件，写失败只记日志。
- Redis 会话值改为 JSON，包含 sid、登录方式、IP、UA、创建时间；旧值读取时就地升级，不强制下线。
- `consents` 增加 `version`、`revoked_at`、`last_used_at`。撤销改为软撤销并递增版本，access token 带 `ver`，由 userinfo、introspect 与刷新链路校验，IdP 侧立即失效。
- 新增接口：`GET/DELETE /api/me/sessions`、`GET/DELETE /api/me/authorizations`、`GET /api/me/events`、`GET /api/admin/events`、`POST /oidc/introspect`。
- 注销账号时事件匿名化，清空 `user_id`、`actor_id`、`ip`、`user_agent`；`relayctl audit prune` 负责按时间清理。
- 前端账号页增加登录设备、已授权应用、登录记录；管理端增加审计面板。
- 账号页最终改为身份摘要加 6 个入口的单列概览，个人资料与用户组收进子页面；子页面用 `?section=` 与 pushState，浏览器后退可返回，600px 高视口不再滚动。
- 账号卡片固定最高 540px，头部与底栏固定，子页面内容区用 OverlayScrollbars 悬浮滚动，不改变页面整体高度；切换 section 有 180ms 淡入上移动画。
- 边界：第三方离线验签的 JWT 无法即时失效，需要应用调用 userinfo 或 introspect；文档已注明。
