# 2026-11-20

## 账号页移动端适配
- web/src/pages/Account.tsx：底栏「退出登录 / 我管理的用户组 / 管理后台」在 <640px 退化为纯图标按钮（LogOut / Users / Settings2），文字用 `hidden sm:inline` 隐藏，靠 aria-label 与 title 补语义；按钮宽度用 `h-9 w-10 sm:w-auto`，w-10 正好等于图标 16px + 默认 `has-[>svg]:px-3`。
- 注意：不要用 `has-[>svg]:px-0` 覆盖默认 padding，Tailwind v4 中 px-3 规则排在 px-0 之后，同特异性会盖掉。
- 页面内边距改为 `px-5 sm:px-7`，375px 下卡片设置项标题文字不再截断。

## 滚动容器统一 OverlayScrollbars
- 新增 `web/src/components/ui/scroll-area.tsx`，导出共享 `scrollOptions`（os-theme-relay、autoHide never）与 `ScrollArea` 组件，作为全站滚动容器唯一入口。
- 覆盖点：Modal 内容区（max-h-[68vh] 挂在 host 上）、管理后台与组长工作台侧栏导航及主区、审计表横向滚动、PageShell 与登录页整页滚动、用户中心原有两处。
- 页面外壳从 `min-h-screen` 改为 `h-dvh overflow-hidden`，页面级滚动全部交给 ScrollArea；Admin/Leader 侧栏不再需要 sticky。
- PageShell 新增 `footer` 属性，登录页改为复用 PageShell，消除重复外壳。
- 注意：OverlayScrollbars 的 max-height 必须放在 host 上才能生效，内边距要放到内层元素，host 自身不留 padding。
